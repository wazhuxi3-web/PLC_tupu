## 真实参数流验证

当前离线程序中的实际位置是 **FC231 / Network 4 / 调用指令 67 → FC156**，并非保存源码声明的 FC400。

```text
I920.0 / QS310
  → FC231 中本次调用前的 L102.5
  → FC156.M_QS（IN）
  → FC156.M_FW（OUT）→ Q1420.0 / 310_FW
  → FC156.M_BW（OUT）→ Q1420.1 / 310_BW
```

这是潜在布尔依赖路径：M_QS 参与手动运行分支，仍受到 READY_X、OP_AUTO、OP_FW/OP_BW、M_Select 等条件约束。选中 M_QS 的局部图不会展示全部其他输入；选择“全部参数”或查看网络证据才可查看相关输入。不能将这条路径解释为 I920.0 为 1 时输出必然为 1。

证据来自 FC231 指令 52、53、67，以及 FC156 的 Network 2、3。调用实参中读取库返回的 `A 1420.0` 按德文操作数规则规范为 `Q1420.0`；原始实参仍在参数表保留。

FC400 离线块为 27 个 Network、1,349 行；两份保存源文件为 129 和 64 个 Network。因此保存源码只作为附属资料，未用于替换当前离线块。
