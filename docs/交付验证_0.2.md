# 0.2 离线交付验证

当前任务边界：离线点位追踪工具，保留 Dify 查询接口，在实际接入 Dify 前停止。

## 实测功能

- 页面粘贴工程文件夹，识别 .S7P，点击导入，显示进度并自动加载新快照。
- L0226D02 导入结果：3 程序、304 块目录、162 已解析、668 调用点、6155 符号，13 保护块、129 系统块/变量表仅目录。
- 输入 MW17：FC239 直接读 16 处、写 2 处；DB26.DBW84 和 MW28 为两路赋值来源，MW48 与 DB26.DBW14 为数值去向。相关调用 OB1 → FC239。
- 来源继续追踪：常量 0 → MW28 的证据为 FC200 Network 3 指令 10～11；MW28 → MW17 为 FC239 Network 6 指令 1615～1616。
- 点位流程图区分数值与条件关系，支持内部循环显示、未知来源和截断边界；连线与列表均可打开指令证据。
- QS310/I920.0 自动点位查询与设备 310 局部参数案例保留。局部参数图 7 节点、6 关系，FC156 布尔网络覆盖 2/3。
- Windows 文件夹选择器已实现，窗口构造通过；页面的路径输入、工程识别和导入链路已完成自动化实测。
- 本地页面测试未发现浏览器控制台错误。

## 已知范围

图是静态潜在依赖，不判定实际执行分支或现场当前值。没有完整控制流可达性分析、间接寻址、内存重叠、完整嵌套调用实例或 PLC 在线采集；保护块保持不可解析状态。系统块仅列目录，不能推断其内部传递。该边界在 UI、查询 JSON 与 Dify 接续文档中同时保留。

离线包内含本机验证过的 Windows x64 运行环境和依赖。仅验证当前电脑，不声称已覆盖所有 Windows 版本。压缩包不含用户完整 PLC 工程和 data 目录，docs/examples 中保留局部实测接口响应。
