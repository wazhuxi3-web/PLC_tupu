# STEP7 程序图谱与参数流工作台

**0.2.0 离线版**：支持选择完整 STEP7 Classic 工程文件夹，导入后输入点位即可查看直接使用块、来源与去向流程图，也支持调用图谱、符号读写和逐调用点参数绑定。当前停在 Dify 接入之前，已保留 v1 查询接口和接续开发文档。

实际采用 **DotNetSiemensPLCToolBoxLibrary 4.4.10** 读取 `.S7P` 及其配套文件。ARES 尚未引入；复杂控制流和完整跨多层调用追踪仍待实现。

## 使用离线包

1. 将 `release/STEP7-Explorer-0.2.0-win-x64.zip` 解压到可写文件夹。不要在压缩包内直接运行。
2. 双击解压目录中的 **`启动工作台.cmd`**。浏览器自动打开 `http://127.0.0.1:4173`。
3. 点击 **选择文件夹…**，选择包含 `.S7P` 和配套目录的完整工程文件夹。也可以粘贴完整路径，再点 **识别工程**。
4. 确认工程入口和文字编码，中文项目通常使用默认 CP936，点击 **导入并打开**。
5. 导入完成后直接使用图谱，无需重启。关闭启动窗口会停止本地服务；下次启动会恢复上次成功的工程。

离线包面向 Windows x64，内含 Node.js、PowerShell 7 和读取库，运行时不需要联网、安装 npm 依赖或 .NET SDK。已经在当前 Windows 电脑验证；其他电脑的系统兼容性仍需实际验证。请将整个目录一起保留，包括隐藏的 `.tools` 文件夹。源码目录的启动入口可使用本机 Node.js/PowerShell 7；便携包优先使用自带运行环境。

同时运行多个副本时，默认端口只会打开已运行的工作台。需要切换副本时先关闭之前的启动窗口。

## 用现有工程体验

工程文件夹：`C:\Program Files (x86)\Siemens\Step7\S7Proj\L0226D02`

1. 选择 `L0226D02 · CPU 416-3 PN/DP`。
2. 点击“参数流”，再点“打开设备 310 验证案例”。
3. 默认关注 `M_QS`，查看 `I920.0 → L102.5 → FC156.M_QS → M_FW/M_BW → Q1420.0/Q1420.1`。
4. 在“图中关系的指令证据”里点击“查看证据”，检查调用位置或块内逻辑。
5. 在“符号与读写”搜索 `QS310`，查看它在 FC202、FC231 中的直接读取位置。

箭头表示静态潜在影响，不是实时状态，也不表示输入置位就必然驱动输出。当前参数图按单个调用点展开；全部逻辑条件以网络证据为准。

## 数据保存与边界

导入器先创建本地独立副本，记录文件摘要并检查导入期间文件变化，再读取副本。原工程保持只读。工程应位于独立目录，不能包含本工具的数据输出目录。文件夹识别最多查找两层子目录；没有发现工程时请选择更具体的目录。

- `data/current.json`：当前成功导入的指针；失败导入不覆盖上次成功结果。
- `data/imports/<导入标识>/`：工程目录、符号、调用、逐块指令、来源清单和诊断。
- `data/snapshots/<导入标识>/`：完整工程副本。每次导入都会保留独立副本，占用相应磁盘空间。

软件不连接现场 PLC，不写入 PLC，也不调用在线模型或 Dify。离线压缩包不含原 PLC 工程或完整解析数据；接口样例中保留了已验证的局部图数据。

实际样本：3 个程序、304 条块记录、162 个已解析块、668 个调用点、6,155 个符号。13 个块有保护标记，129 条系统块/变量表仅列目录。已尝试解析的块没有解析失败。

参数流页只覆盖支持的完整直线布尔网络；点位追踪页还支持分段数值赋值、常用运算与比较条件。跳转边界和未知操作会停止合并状态，间接寻址尚未支持；这不是整个 PLC 的完整数据流分析。数组结构暂不逐元素展开。保存的两份 FC400 源码与当前离线块不同，未混入图谱。

## 点位追踪（新增的主要入口）

选择程序 / CPU 后，在默认“点位追踪”页输入 `MW17`、`I920.0` 或完整符号名。结果自动包含直接读写块、相关调用点、上游来源、下游去向和可点击证据的流程图。

图中实线表示数值依赖或参数传递，虚线表示比较、布尔或定时器条件影响。流程图上方的两个开关可以分别隐藏或显示实线、虚线，切换时不会删减下方的完整证据列表。数值关系覆盖可识别的 L/T 和常用运算；不会把“参与比较”误写成“数值直接复制”。常量、外部输入、内部数据、未知来源和内部循环分别保留。

L0226D02 中的 `MW17`：直接使用块 FC239，18 处直接引用（16 读、2 写）；写入来自 DB26.DBW84 和 MW28，数值继续传给 MW48、DB26.DBW14。FC239 由 OB1 调用。两路赋值都有条件，离线图不判断当前哪一路执行。

点位图在控制转移和未知指令处分段，保留已明确的局部传递，不把分支前的累加器值直接延续到分支后。默认上下游各最多 6 层、90 节点、240 条证据边；达到上限会标注边界，可输入边界地址继续查。未完整展开嵌套调用实例、间接寻址或重叠地址。图中“来源未解析”不等于没有来源。
